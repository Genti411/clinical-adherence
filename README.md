# Clinical Adherence

Foundation monorepo for the clinical care-plan adherence product. This repo contains the shared exercise library, the Supabase database schema with row-level security, a local test seed, and a Dockerized RLS test harness. For context on the product concept see `../flexai-coach/docs/clinical-adherence-concept.md`. Note: no real PHI will be stored until a BAA is in place.
